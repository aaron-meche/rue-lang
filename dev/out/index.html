The Rue Studio loop
Rue Studio should make the language feel tangible: write the file, watch the compiler work, and inspect exactly what the runtime creates
Write
Compose Rue syntax with component config, CSS-like styles, Interface output, imports, and live state in focused files
Compile
Run the TypeScript compiler, surface diagnostics, and keep parser behavior readable enough to debug quickly
Preview
Render UIElement output as static HTML while preserving enough runtime behavior for stateful demos
